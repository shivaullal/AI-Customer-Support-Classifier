# 🤖 AI Customer Support Ticket Classifier

An AI-powered customer support system that automatically analyzes support tickets and predicts their **category, priority, department, and sentiment** using Machine Learning.

## 🚀 Features

- 🎯 AI Ticket Classification
- 📊 Category & Priority Prediction
- 😊 Sentiment Analysis
- 🏢 Department Prediction
- 📈 Prediction Confidence
- 💡 AI Recommendations
- 📊 Interactive Dashboard
- 🐳 Docker Support

## 🛠️ Tech Stack

- Python
- FastAPI
- Scikit-learn
- TF-IDF
- Logistic Regression
- HTML, CSS, JavaScript
- Docker
